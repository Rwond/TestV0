Je veux construire progressivement un agent IA personnel qui pourra plus tard être contrôlé depuis WhatsApp et interagir avec Git, GitHub, LinkedIn et ma machine.

Je suis développeur web, mobile et backend, mais je ne suis pas spécialisé en intelligence artificielle. Je connais Node.js, TypeScript, les API REST, Git et les architectures backend.

Je veux apprendre en construisant le projet moi-même. Ne génère donc pas tout le projet d'un seul coup et ne cache pas les concepts derrière des frameworks complexes.

========================
VERSION 0 — AGENT LOCAL
========================

Pour commencer, je veux uniquement construire :

Utilisateur
   ↓
Node.js / TypeScript
   ↓
LLM Claude
   ↓
Git Tool
   ↓
Résultat
   ↓
LLM
   ↓
Utilisateur

L'objectif est de pouvoir écrire depuis mon terminal quelque chose comme :

"Analyse les modifications de mon projet et propose-moi un message de commit."

L'agent doit être capable de :
1. recevoir mon message ;
2. l'envoyer au LLM ;
3. fournir au LLM un outil Git ;
4. permettre au LLM de demander l'utilisation de cet outil ;
5. exécuter réellement la commande Git côté Node.js ;
6. retourner le résultat du Git au LLM ;
7. laisser le LLM analyser le résultat ;
8. me retourner une réponse compréhensible.

Pour cette première version, je veux comprendre le concept de "tool calling".

IMPORTANT :
- Utilise TypeScript et Node.js.
- Utilise l'API Claude/Anthropic.
- N'utilise pas encore WhatsApp.
- N'utilise pas encore MCP.
- N'utilise pas encore GitHub.
- N'utilise pas encore LinkedIn.
- N'ajoute pas PostgreSQL, Redis ou Docker si ce n'est pas nécessaire.
- Évite les frameworks d'agents complexes.
- Je veux comprendre ce que fait réellement le code.

Commence par m'expliquer l'architecture générale et le rôle exact de chaque composant.

Explique-moi particulièrement :
1. Qu'est-ce qu'un LLM dans cette architecture ?
2. Qu'est-ce qu'un agent ?
3. Quelle est la différence entre une requête classique à un LLM et un agent utilisant des tools ?
4. Qu'est-ce que le tool calling ?
5. Comment le LLM sait-il quels tools sont disponibles ?
6. Est-ce que le LLM exécute réellement "git diff", ou est-ce mon serveur Node.js qui l'exécute ?
7. Comment circule l'information entre Node.js, Claude et Git ?

Ensuite, propose-moi une architecture de dossiers simple.

Puis construis le projet étape par étape.
